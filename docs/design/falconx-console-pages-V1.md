> 阶段 1 R3 单端管理端核心页面设计。客户端按 V2 §3 阶段 1 三端要求豁免。
>
> 本文件依赖 [`falconx-console-DESIGN.md`](./falconx-console-DESIGN.md)（设计系统 + 品牌 token）与 [`管理端接口规范.md`](../api/管理端接口规范.md) §2 已冻结契约。

## §1. P1 登录 + 重置密码

### 1.1 路由与流程

```
[未登录]
   │
   ▼ /admin/login (P1.A)
   │
   ├─ 输入用户名 + 密码 → POST /admin/auth/login
   │      │
   │      ├─ 90001 用户名或密码错误 → 行内错误，停留登录页（计数 +1）
   │      ├─ 90006 锁定 → Result error 全屏提示 + 倒计时
   │      ├─ 90008 账号禁用 → Result error 全屏提示 + 联系超管
   │      └─ code=0
   │             │
   │             ├─ data.mustChangePassword=true → 跳转 /admin/change-password (P1.B 强制)
   │             └─ data.mustChangePassword=false → 跳转 /admin (主页)
   │
[已登录后主动改密]
   │
   ▼ Avatar 下拉 → "修改密码" → /admin/change-password (P1.B 主动)
```

**AntD 组件**：

| 区域 | 组件 |
| --- | --- |
| 居中容器 | `<Layout>` + flex center |
| 卡片 | `<Card bordered={false}>` 宽 420px |
| 表单 | `<Form layout="vertical">` |
| 用户名 | `<Form.Item rules={[{ required, min:3 }]}>` + `<Input prefix={<UserOutlined/>} size="large">` |
| 密码 | `<Form.Item rules={[{ required, min:8 }]}>` + `<Input.Password prefix={<LockOutlined/>} size="large">` |
| 登录按钮 | `<Button type="primary" htmlType="submit" size="large" block loading={isSubmitting}>` |
| 错误展示 | `<Form.Item>` 行内 + 全局 `<Alert type="error" closable>` 顶部 |
| 锁定 / 禁用 | `<Result status="error">` 替代整个卡片 |

**状态表**：

| 状态 | 视觉 |
| --- | --- |
| 初始 | Form 默认；登录按钮可点 |
| 提交中 | 登录按钮 `loading={true}`；输入框 `disabled` |
| 90001 用户名/密码错误 | 顶部 `<Alert>` 红色「用户名或密码错误（已失败 N 次）」；密码框清空但保留用户名 |
| 90006 锁定 | 整个 Card 替换为 `<Result status="error" title="账号已锁定" subTitle="登录失败次数过多，请 30 分钟后重试">`，无重试按钮 |
| 90008 账号禁用 | `<Result status="error" title="账号已禁用" subTitle="请联系超级管理员">` |
| 网络错误 | 顶部 `<Alert>` 黄色「网络异常，请检查 VPN/IP 白名单」；保留用户输入 |
| IP 不在白名单（90005，由 gateway 拦截） | 浏览器看到 403；前端兜底 `<Result status="403" title="访问被拒" subTitle="您的 IP 不在管理后台白名单内">` |

**响应式**：

| 断点 | 行为 |
| --- | --- |
| ≥ 1024px | 卡片 420px 居中 |
| < 1024px | 卡片宽度 90vw，最小 320px |

**数据依赖**：

- `POST /admin/auth/login`（[管理端接口规范 §2.1](../api/管理端接口规范.md#21-管理员登录)）
  - 请求：`{ username, password }`
  - 成功：`{ adminUserId, username, realName, roles, mustChangePassword, accessToken, refreshToken, accessTokenExpiresIn, refreshTokenExpiresIn }`
  - 错误：`90001 / 90006 / 90008`
- 客户端**禁止**记录完整 token 到 console / 错误详情；token 写入 sessionStorage（按 DESIGN.md §10）
- 失败次数计数仅前端展示用，真实计数与锁定阈值由后端持有

**禁止事项**：

- ❌ 禁止「记住我」选项（管理后台不接受持久化登录）
- ❌ 禁止社交登录 / SSO（一期不做）
- ❌ 禁止"显示密码"按钮以外的明文密码呈现
- ❌ 禁止在 URL 中传递任何鉴权参数

**AntD 组件**：

| 区域 | 组件 |
| --- | --- |
| 强制提示 | `<Alert type="warning" showIcon message="首次登录..." />`（仅强制时） |
| 三个密码 | `<Form.Item>` + `<Input.Password size="large">` |
| 密码强度 | 自定义组件：5 段 `<Progress percent steps={5}>` + 文字「弱/中/强」 |
| 提交 | `<Button type="primary" htmlType="submit" block loading>` |
| 取消（主动） | `<Button onClick={navigate('/admin')}>` |

**密码规则**（前端提示，最终以后端校验为准）：

- 至少 12 字符
- 至少 1 个大写字母
- 至少 1 个小写字母
- 至少 1 个数字
- 至少 1 个特殊字符（`!@#$%^&*`）
- 不得与旧密码相同（前端不校验，后端拒绝时显示）
- 不得与用户名相同（前端不校验，后端拒绝时显示）

**状态表**：

| 状态 | 视觉 |
| --- | --- |
| 强制改密时 | 顶部 `<Alert warning>` 不可关闭；隐藏取消按钮 |
| 主动改密时 | 无 Alert；显示取消按钮可返回上一页 |
| 提交中 | 按钮 `loading`；输入框 `disabled` |
| 旧密码错误 | 旧密码 `<Form.Item validateStatus="error" help="...">` |
| 新密码不符合规则 | 新密码下方红字提示 + 强度条 |
| 确认密码不一致 | 确认密码 `<Form.Item validateStatus="error" help="两次密码不一致">` |
| 修改成功 | `message.success('密码修改成功，请重新登录')` + 强制清空 token + 跳转 `/admin/login` |

**响应式**：与 P1.A 一致。

**数据依赖**：

- `POST /admin/auth/change-password`（[管理端接口规范 §2.4](../api/管理端接口规范.md#24-修改密码首次登录强制--主动修改)）
  - 请求：`{ oldPassword, newPassword }`
  - 成功后：旧 access/refresh token 全部失效，前端必须强制重新登录

**禁止事项**：

- ❌ 禁止本地保存任一密码值
- ❌ 禁止前端"密码强度评分"覆盖后端规则（仅作为视觉提示）
- ❌ 修改成功后**禁止**自动登录（必须重新走完整 login 流程）

### 2.4 权限点埋点

| 操作 | 权限码 | 按钮渲染 |

### 6.2 路由结构

```

### 6.3 鉴权保护

- 路由进入前：`useAuthGuard` hook 校验 sessionStorage token + 过期时间；token 缺失或过期 → 跳转 `/admin/login`
- API 调用：`401` → 触发单飞 refresh；refresh 失败 → 清空 token + 跳转 `/admin/login`
- 路由进入前：`usePermissionGuard(code)` hook 校验权限；无权限 → `<Result status="403">`

### 6.4 通用错误展示约定

- ❌ 引入 lucide-react 等其他图标库（仅 `@ant-design/icons`）
- ❌ 引入 `tailwindcss` / `styled-components` / `emotion` 等平行样式系统

│ │ Admin User ID:[输入]  Permission Code:[输入]            │ │
│ │ Target Type:[选择]    Target ID:[输入]                  │ │
│ │ Risk Level:[全部▼]                                     │ │
│ │ 时间范围: [起始]-[结束]    [查询] [重置]                  │ │
│ └─────────────────────────────────────────────────────────┘ │

```

列定义：

| 列 | dataIndex | 渲染 | 宽度 |
| --- | --- | --- | --- |
| ID | `id` | monospace | 160 |

| 权限码 | `permissionCode` | Tag | 200 |
| 风险等级 | `riskLevel` | `<Tag>`: LOW=default / MEDIUM=warning / HIGH_RISK=error | 110 |
| 操作对象 | — | 拼接 `${targetType}/${targetId}`，`null` → "—" | 200 |
| IP | `ip` | 等宽 | 140 |
| 时间 | `occurredAt` | `YYYY-MM-DD HH:mm:ss` | 160 |
| 操作 | — | 「详情」按钮触发 Drawer | 80，fixed:"right" |
