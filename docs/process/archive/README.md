## 使用原则

1. 需要追溯某次审计结论时再读取
2. 若归档中的问题重新打开，回到 [`../统一问题清单.md`](../统一问题清单.md) 继续跟踪，**不在归档文件中恢复状态**
3. 新的单次分析、审阅材料不得长期单独保留；有保留价值的结论必须收敛进已归档问题清单或明确命名的专项归档
4. 归档正文可能保留当时的文件名、章节号或旧规则说法，**不能反推当前口径**
